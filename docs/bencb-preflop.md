# Bencb 프리플랍 차트

사이트 메뉴의 **Bencb 프리플랍**에서 카테고리, 스택/포지션, 상황을 선택합니다. 13×13 차트에서 핸드를 누르면 해당 핸드의 색상별 비율을 확인할 수 있습니다. 선택한 차트의 JSON 보기와 전체 JSON 다운로드를 지원합니다.

## 데이터 범위

- PNG 172개 중 정상 차트 171개, 차트당 169개 핸드입니다.
- 혼합 셀 227개의 비율은 색상 폭에서 추정했습니다. 일부 스퀴즈 차트는 원본 콤보 합계도 함께 대조했습니다. 개별 핸드의 숫자 빈도가 원본에 명시된 것은 아닙니다.
- 원본 범례가 누락된 4개 차트의 해당 색상은 `label: null`로 보존합니다.
- 잘린 이미지 1개는 `incomplete_sources`에 기록합니다.
- 흰색 `unmarked`는 미표시 영역이며 자동으로 fold 액션으로 해석하지 않습니다.
- 범례의 `source_percent`는 레인지 내 비중입니다. 핸드별 비율과 다릅니다.

## 로컬 데이터 준비

기존 `DATA_KEY`를 환경변수로 설정한 터미널에서 실행합니다. 명령은 `.env.local`을 자동으로 읽지 않습니다.

```sh
npm run decrypt
npm run dev
```

`npm run decrypt`는 세 차트의 `.enc`를 복호화하고 JSON을 검증합니다. 모든 파일의 변환과 검증에 성공한 후 각 평문 파일을 원자적으로 교체합니다. 변환이나 검증이 실패하면 기존 파일을 보존하고 임시 파일을 정리합니다. 여러 파일의 최종 교체 전체가 하나의 파일시스템 트랜잭션인 것은 아닙니다.

평문 데이터를 갱신한 뒤 암호화본을 만들려면 동일한 키가 설정된 터미널에서 실행합니다.

```sh
npm run encrypt
```

Git에는 `public/bencb-preflop-charts.json.enc`만 보관합니다. `public/bencb-preflop-charts.json`, `output/bencb-preflop/*.json`, 변환 중 생성되는 임시 디렉터리는 Git에서 제외됩니다.

Vercel의 기존 `npm run build:vercel`은 복호화 후 사이트를 빌드합니다. 이 암호화는 Git의 데이터 보관 방식이며, 사이트에서 복호화된 정적 JSON에 대한 접근 권한을 추가하는 기능은 아닙니다.

## 검증

```sh
npm test
npm run build
npm run lint
```

페이지 테스트는 합성 데이터로 실행하므로 평문 원본이나 `DATA_KEY` 없이도 실행됩니다. `npm test`에는 정상 암복호화, 손상된 암호화본, 잘못된 키, JSON 검증 실패, 키 누락 시 기존 파일 보존을 확인하는 Node 테스트도 포함됩니다.
