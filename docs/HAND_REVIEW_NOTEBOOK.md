# CoinPoker 복기 노트

CoinPoker 페이지 상단의 **복기 노트**에서 저장한 핸드를 확인합니다. 분석 목록에서 핸드 상세를 열고 **복기 노트에 저장**을 누르세요. 서버가 저장을 확인한 뒤에만 `노트에 저장됨`으로 바뀝니다.

- Cash / Tournament와 핸드 ID를 함께 식별자로 사용합니다. 같은 핸드를 다시 저장해도 원문과 기존 메모를 덮어쓰지 않습니다.
- 핸드 ID, 게임 종류, 날짜, Hero 핸드/포지션, 원문을 별도 저장합니다. CoinPoker 업로드 기록을 지워도 노트는 남습니다.
- **당시 생각**, **복기 결론**을 입력하고 **메모 저장**을 누르세요. **완료로 저장**은 입력 중인 메모도 함께 저장합니다. 완료 목록에서 **미완료로 되돌리기**로 다시 검토할 수 있습니다.
- 메모는 자동 저장되지 않습니다. 편집 후 목록 필터를 바꾸거나 노트를 닫거나 페이지를 떠나기 전에 저장하세요.
- **노트 삭제 → 삭제 확인**은 저장한 원문과 메모를 삭제합니다. 업로드 분석 기록은 삭제하지 않습니다.

노트는 로그인한 계정의 `/api/hand-reviews`를 통해 서버에 저장합니다. 브라우저 공용 localStorage에는 보관하지 않습니다. 일반 Vite 개발 서버에는 이 API가 없으므로 계정 저장 검증은 `vercel dev` 또는 Vercel 환경에서 진행해야 합니다.

불러오기 실패는 빈 노트로 간주하지 않습니다. 다시 불러오기 전까지 신규 저장을 막고, 서버도 기존 데이터를 읽을 수 없으면 쓰기를 중단합니다. 저장 실패는 화면에 표시하며 성공 상태로 바꾸지 않습니다. 편집 화면의 입력은 유지되므로 연결이 복구되면 다시 저장할 수 있습니다.

계정당 최대 500개, 전체 UTF-8 JSON 3 MB, 핸드 원문 100,000자, 메모 항목별 10,000자로 제한합니다. 용량을 초과하면 기존 노트를 정리해야 합니다. 기존 앱과 같은 Vercel Blob 단일 파일 읽기·수정·덮어쓰기 방식이므로 여러 탭/기기에서 동시에 수정하면 마지막 쓰기가 앞선 수정을 덮어쓸 수 있습니다. 한 탭에서 편집하세요. Blob은 기존 저장소의 public access 설정을 사용하며, 앱 API는 계정 인증을 요구하지만 Blob URL 자체는 비공개 접근 제어를 제공하지 않습니다.

이 기능은 수동 복기 메모입니다. 자동 전략 분석이나 스트리트별 리플레이를 제공하지 않습니다.
