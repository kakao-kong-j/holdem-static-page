# Flop C-bet Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** XLSX 원본 데이터를 보존하는 JSON과 플랍 베팅 빈도 조회 페이지를 제공한다.

**Architecture:** Python ZIP/XML 변환기로 독립된 JSON을 생성한다. TypeScript 데이터 모듈에서 검증·조회·요약을 수행하고 React 페이지에서 표시한다. 기존 메뉴와 암호화 배포 흐름에 연결한다.

**Tech Stack:** Python 표준 라이브러리, React 19, TypeScript, Vite, Vitest, 기존 OpenSSL 암호화 스크립트.

**Spec:** docs/superpowers/specs/2026-09-12-flop-cbet-design.md

## Global Constraints

- 조회만 구현하며 트레이너는 제외한다.
- frequency_pct는 0–100이며 size.pct는 팟 대비 베팅 사이즈이다.
- 4BP는 50BB만 제공한다. 없는 조합은 선택 목록에 노출하지 않는다.
- 기존 테스트 최적화 변경과 관계없는 원본·출력 파일은 보존한다.
- worktree 생성은 sandbox에서 거부되어 스킬의 fallback에 따라 현재 checkout에서 작업한다.

Produces: JSON schema_version=1, source, boards, records, corrections.

- [x] 합성 XLSX로 숫자/수트/올인/Stab/링크 변환, 중복·비정상 빈도 거부와 출력 보존을 테스트하고 미구현 실패를 확인한다.
- [x] workbook relationships로 DATA 시트를 찾고 shared/inline strings와 cached values를 읽는다. 원본 행별 출처를 부착한다.
- [x] 원본 3개 숫자 오타만 허용된 규칙으로 정규화한다. 각 행을 schema에 매핑하고 전략키 중복과 보드 중복 카드를 거부한다.
- [x] `python3 -m unittest discover -s scripts -p 'test_convert_flop_cbet.py'`를 통과시킨다.
- [x] 원본 XLSX 변환 후 전체 원본 수치·링크, 7938행/49보드/162상황과 독립 대조하고 docs에 재생성 명령을 남긴다.
