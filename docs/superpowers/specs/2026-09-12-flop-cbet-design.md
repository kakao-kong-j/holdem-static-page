# 플랍 C-bet 조회

승인된 범위: 첨부 XLSX를 JSON으로 재가공하고 조회·그래프 페이지만 추가한다. 트레이너는 제외한다.

## 데이터

- 원본 XLSX의 숨김 DATA_* 시트 7개, 7,938행과 49개 보드를 사용한다. 화면 셀의 현재 선택값이나 이미지의 색상으로 빈도를 추정하지 않는다.
- JSON v1은 source(파일명·SHA256), boards(id·cards), records, corrections를 가진다.
- records는 spot, profile, stack_bb, hero, villain, action(cbet/stab), board_id, size(kind=pot/pct 또는 all-in), frequency_pct(0–100), source(sheet·row·url)를 보존한다.
- Calling Station과 Maniac은 원본 프로필 이름이다. 노드락 설정의 구체적 가정은 추측하지 않는다.
- 4BP는 50BB만 제공한다. 없는 조합은 선택 목록에 노출하지 않는다.
- 콤마 소수점 두 건과 마지막 마침표 한 건은 명시적으로 정규화하고 원문·셀·수정값을 기록한다. 기타 잘못된 값, 중복 전략 키, 잘못된 보드, 누락 필드는 변환 실패로 처리한다.
- 원본 이미지 링크를 보존한다. 이미지는 XLSX에 내장되어 있지 않으므로 조회 화면의 모달에서 Google Drive 미리보기로 표시하며, 외부 서비스의 접근 권한은 그대로 적용된다.

## 페이지

- 기존 VIEWS 메뉴에 플랍 C-bet을 추가한다. 기존 전역 프리플랍 스택 탭은 사용하지 않는다.
- 첫 선택은 SRP IP / GTO / 50BB / BTN vs BB이다.
- 상황, 상대 유형, 스택, 포지션 선택을 제공하며 상황 변경 시 유효한 스택/포지션으로 보정한다.
- 보드 검색은 AK3 같은 랭크와 AsKs3h 또는 수트 기호 표기를 지원한다. 원본 순서/빈도 높은 순/낮은 순으로 정렬한다.
- 각 행에 3장의 카드, 팟 대비 베팅 사이즈(올인은 별도), 정확한 빈도 숫자와 가로 막대, 원본 이미지 모달 버튼을 표시한다. Blind War의 Stab은 별도 액션으로 표시한다.
- 조회 중인 보드의 단순 평균 빈도 및 사이즈별 보드 수·단순 평균을 표시한다. 전체 가능한 플랍의 가중 평균으로 표현하지 않는다.
- 로딩, 데이터 형식 오류, 네트워크 오류와 재시도, 검색 결과 없음, 필터 초기화를 처리한다.
- JSON 다운로드와 원본/변환 안내를 제공한다. 모바일에서도 카드·빈도·사이즈가 읽혀야 한다.

## 통합 및 검증

기존 public JSON + 암호화 파일 보관 패턴을 따른다. 평문 JSON은 Git에서 제외하고 .enc 파일을 추가한다. 기존 암호화 파일 3개는 재생성하지 않는다.

변환기는 Python 표준 라이브러리로 XLSX ZIP/XML을 읽어 외부 패키지 없이 재실행할 수 있게 한다. 독립적인 합성 XLSX로 파싱과 실패 시 출력 보존을 검증한다. 실제 원본은 7,938행·49보드·162상황·3수정 사항 및 원본 수치와 전체 대조한다. UI의 의존 필터, 정렬·검색·요약, Stab/ALLIN, 실패 복구를 합성 데이터로 테스트한다. 전체 테스트·린트·빌드 및 브라우저 확인 후 완료한다.
