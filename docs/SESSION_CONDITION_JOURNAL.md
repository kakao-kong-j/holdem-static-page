# 세션 컨디션 기록

뱅크롤의 Records에서 각 세션 이름 아래 **컨디션 기록**을 누릅니다. 캐시와 토너먼트 모두 기록할 수 있습니다.

- 집중도: 1은 낮음, 5는 높음입니다.
- 피로도·틸트: 1은 낮음, 5는 심함입니다.
- 점수는 각각 선택 사항이며 **미기록**으로 되돌릴 수 있습니다. 메모는 최대 2,000자입니다.

**컨디션 저장**을 누르면 로그인한 사용자의 서버 저장소에 기록합니다. 저장 후 목록에서 점수와 메모를 확인할 수 있고, **컨디션 수정**으로 다시 편집합니다. **컨디션 기록 지우기**는 해당 세션의 점수와 메모를 모두 삭제하고 금액은 유지합니다. **취소**는 편집 중인 입력만 버립니다.

같은 토너먼트 ID 또는 캐시 세션 ID를 JSON으로 다시 가져오면 금액 필드는 기존처럼 덮어쓰지만, 컨디션 기록은 유지됩니다. 캐시와 토너먼트의 ID가 같아도 기록은 서로 분리됩니다. 지운 기록은 다음 원본 JSON 가져오기로 되살아나지 않습니다. 티켓 상금과 손익 계산 방식은 그대로입니다.

컨디션 저장은 서버의 최신 세션에서 기록 필드만 갱신합니다. 서버 저장이 실패하면 오류를 표시하고 편집 입력을 유지하므로 다시 시도할 수 있습니다. 일반 Vite 개발 서버처럼 `/api`가 없는 환경에서는 서버 저장이 되지 않습니다. 기존 저장소와 마찬가지로 여러 기기에서 동시에 쓰는 경우의 충돌 해결은 지원하지 않습니다.
